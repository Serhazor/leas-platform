# Guide de l'administration

Bienvenue ! Ce guide explique comment gérer votre site vous-même, sans aucune connaissance technique.

## Se connecter

- Adresse : **votre-site.fr/admin**
- Saisissez votre e-mail et votre mot de passe.
- Mot de passe oublié ? Cliquez sur **« Mot de passe oublié ? »** : un lien vous est envoyé par e-mail.
- Pour changer votre mot de passe : **Mon compte** (en bas du menu).

L'administration fonctionne aussi sur téléphone : le menu s'ouvre avec le bouton **Menu** en haut à droite.

## Tableau de bord

Vous y trouvez en un coup d'œil :
- les **demandes de rendez-vous à valider** ;
- vos **prochains rendez-vous confirmés** ;
- les **derniers messages** reçus ;
- une liste **« À compléter »** (informations utiles avant la mise en ligne) ;
- l'**activité récente**.

## Réservations

**Réservations** affiche la liste (filtrable par statut, service, période, ou par recherche)
et un **calendrier** mensuel.

Ouvrez une réservation pour :
- **Confirmer** : le client reçoit un e-mail de confirmation (vous pouvez ajouter un message personnel) ;
- **Refuser** : le client est prévenu, vous pouvez lui proposer une alternative ;
- **Annuler** : le créneau est libéré et le client prévenu ;
- **Marquer comme terminé** une fois l'intervention réalisée ;
- ajouter des **notes privées** (jamais visibles par le client).

Les statuts : *En attente*, *Confirmé*, *Refusé*, *Annulé*, *Terminé*.

## Disponibilités

- **Horaires de la semaine** : cochez les jours travaillés et indiquez les heures. Plusieurs plages
  par jour sont possibles (ex. 9:00–12:00 et 14:00–18:00). Cliquez sur **Enregistrer les horaires**.
- **Absences** : congés, jours fériés, rendez-vous personnels. Choisissez « Journée(s) entière(s) »
  ou « Quelques heures ».

Les règles (durée des rendez-vous, temps entre deux rendez-vous, délai minimum, réservation
jusqu'à X jours) se règlent dans **Paramètres → Réservations**.

## Demandes de contact

Les messages envoyés depuis la page Contact. Ouvrez-en un pour lire le message, **répondre par
e-mail**, changer le statut (*Nouveau*, *En cours*, *Traité*) et noter vos remarques internes.

## Services

- **Ajouter un service** : nom, catégorie, descriptions, image, durée, prix…
- **Modifier** : cliquez sur un service, changez le texte ou l'image, puis **Enregistrer**.
- **Masquer** temporairement un service : interrupteur « Visible ».
- **Bientôt disponible** : le service est présenté mais ne peut pas encore être réservé.
- **Ordre d'affichage** : flèches ↑ ↓.
- **Prix** : facultatif ; cochez « Afficher le prix sur le site » pour le rendre visible,
  et « À partir de » si besoin.
- L'onglet **Catégories** permet de renommer, ordonner ou ajouter des catégories
  (ex. « Événementiel » pour vos futurs services).

## Pages du site

Choisissez une page (Accueil, À propos…). Chaque bloc de la page est présenté dans l'ordre :
modifiez les titres, textes, images et boutons, puis cliquez sur **Enregistrer** en bas.
Vos modifications sont visibles immédiatement sur le site.

Mise en forme des textes :
- laissez **une ligne vide** entre deux paragraphes ;
- commencez une ligne par **« - »** pour faire une liste ;
- commencez une ligne par **« ## »** pour un intertitre.

Pour les boutons, choisissez simplement la page de destination dans la liste.
Certains blocs peuvent être masqués (case « Afficher cette section »).

La page **Comment ça marche** contient aussi la gestion des **étapes**.

## Questions fréquentes

Ajoutez, modifiez, supprimez et ordonnez les questions. Deux interrupteurs :
**Visible** (sur la page FAQ) et **Accueil** (affichée aussi sur la page d'accueil).

## Médiathèque

- **Ajouter des images** : envoyez vos photos telles quelles (même depuis votre téléphone) :
  elles sont automatiquement redimensionnées et optimisées.
- Cliquez sur une image pour ajouter une **description** (importante pour l'accessibilité
  et Google), la **remplacer** partout où elle est utilisée, ou la **supprimer**.

## Paramètres

- **Entreprise et contact** : nom, coordonnées, secteur d'intervention, réseaux sociaux, pied de page.
- **Apparence** : logo, icône du site, couleurs et typographie.
- **Réservations** : activer/désactiver la réservation en ligne, mode *Demande de rendez-vous*
  (vous validez) ou *Confirmation immédiate*, durées et délais.
- **Référencement** : titre et description du site pour Google, image de partage.
- **E-mails** : adresse qui reçoit les notifications, nom d'expéditeur, signature, e-mail de test.
- **Informations légales** : dénomination, SIRET, etc. (page Mentions légales).
- **Accès** : donner ou retirer l'accès à l'administration à une autre personne.

## Bon à savoir

- Un bandeau « Modifications non enregistrées » vous prévient si vous quittez une page sans enregistrer.
- Les suppressions demandent toujours une confirmation.
- Les données des clients sont conservées 3 ans puis supprimées ou anonymisées automatiquement (RGPD).
