# Photos livrées avec le site

Déposez ici des photos (JPEG, WebP, PNG ou AVIF). Elles seront servies et optimisées
automatiquement par Next.js / Vercel. Lancez ensuite `npm run db:seed` : les photos
présentes sont ajoutées à la médiathèque et placées aux emplacements ci-dessous
(uniquement là où aucune image n'a encore été choisie depuis l'administration).

| Nom du fichier (sans extension)          | Emplacement                                          |
| ---------------------------------------- | ---------------------------------------------------- |
| `accueil`                                | Bandeau de la page d'accueil + image de partage      |
| `etats-des-lieux`                        | En-tête de la page « États des lieux »               |
| `portrait`                               | Photo de profil (À propos + aperçu sur l'accueil)    |
| `service-etat-des-lieux-entree`          | Service « État des lieux d'entrée »                  |
| `service-etat-des-lieux-sortie`          | Service « État des lieux de sortie »                 |
| `service-inspection-constat-logement`    | Service « Inspection et constat de logement »        |
| `service-conciergerie-a-la-demande`      | Service « Conciergerie à la demande »                |
| `service-assistance-administrative`      | Service « Assistance administrative »                |
| `service-assistance-commerciale`         | Service « Assistance commerciale »                   |
| `service-coordination-evenementielle`    | Service « Coordination d'événements »                |

Conseils : largeur 1600 à 2400 px, moins de 1 Mo par photo (format paysage pour les
services, portrait 4:5 pour `portrait`). Vérifiez que vous disposez des droits
d'utilisation (photos personnelles, Unsplash, Pexels…).
